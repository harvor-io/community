# Harvor Community

Welcome to the Harvor community! 👋

This repository is the central place for community-wide discussion, collaboration, and contribution across the [Harvor](https://harvor.io) open-source ecosystem.

> [!WARNING]
> **Harvor is currently a work in progress.** We're actively building the initial services, shaping the APIs, and establishing the foundations of the project. This is a great time to get involved and help shape Harvor.

## Discussions

[GitHub Discussions](../../discussions) is the best place for conversations that aren't specific to an issue in a particular Harvor project.

Use Discussions to:

- Ask questions
- Share ideas
- Propose new Harvor projects or capabilities
- Discuss architecture and design
- Provide feedback
- Share how you're using Harvor
- Connect with other contributors

For bugs or feature requests related to a specific Harvor project, please open an issue in that project's repository instead.

## Contributing

Contributions to Harvor are welcome!

There are many ways to contribute beyond writing code, including reporting bugs, suggesting features, improving documentation, participating in discussions, reviewing pull requests, and helping other users.

Please read our [Contributing Guide](CONTRIBUTING.md) before getting started.

## Community Guidelines

We want Harvor to be a welcoming, constructive, and professional community.

Be respectful of others, assume good intent, provide constructive feedback, and remember that people participating in the project may have different backgrounds, experience levels, and perspectives.

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) for understanding on how to ensure positive interactions when collaborating on Harvor

## About Harvor

Harvor provides open-source, self-hostable building blocks for the infrastructure modern applications need so developers can focus on building what makes their products unique.

Learn more at **[harvor.io](https://harvor.io)**.
